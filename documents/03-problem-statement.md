# Chapter 3 — Purpose & Problem Statement

## 3.1 Purpose

The purpose of this project is to design and develop a **web-based Employee Management System** that provides a centralized platform for managing employee records, leave workflows, departmental organization, presence tracking, and internal communication — all accessible through a responsive modern interface.

The system aims to:

1. Eliminate manual, paper-based employee record keeping.
2. Automate the leave request and approval workflow.
3. Provide real-time visibility into employee availability and presence.
4. Enable data-driven decision-making through dashboard analytics and exportable reports.
5. Demonstrate a full-stack software engineering project using modern industry technologies.

## 3.2 Problem Statement

> Organizations — particularly small to mid-sized companies — continue to rely on manual registers, spreadsheets, or outdated desktop applications for managing employee data, leave tracking, and internal communication. This leads to data inconsistency, delayed approvals, lack of real-time visibility, and poor scalability.

### Specific Problems Identified

| # | Problem                                                            | Impact                                              |
| - | ------------------------------------------------------------------ | --------------------------------------------------- |
| 1 | Employee data scattered across paper files, Excel sheets, emails   | Data loss, duplication, hard to search               |
| 2 | Leave requests handled via email or paper forms                    | Delays in approval, no tracking, no audit trail      |
| 3 | No centralized announcement system                                 | Important notices missed by employees                 |
| 4 | No visibility of who is online/available                           | Communication gaps, wasted time                       |
| 5 | Manual report generation for management                            | Time-consuming, error-prone                           |
| 6 | No role-based access control                                       | Unauthorized access to sensitive data                 |
| 7 | No backup mechanism for critical HR data                           | Risk of permanent data loss                           |

## 3.3 Motivation

The motivation for this project stems from real-world observations:

- **HR staff** spend hours manually tracking attendance and processing leave forms.
- **Managers** lack a quick view of team availability and pending requests.
- **Employees** have no self-service portal to view their own data or request leave digitally.
- **IT departments** struggle to deploy and maintain legacy desktop HR tools.

A modern, containerized web application solves all of these challenges while being easy to deploy and maintain.
